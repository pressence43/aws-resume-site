
# AWS Cloud Resume Challenge

Welcome to my AWS Cloud Resume Challenge project! This project demonstrates my practical experience building and deploying a cloud-hosted resume website using AWS services and Infrastructure as Code.

## Live Website
[[View My Live Resume Website](https://d3iaraeem199vu.cloudfront.net)]

## AWS Architecture

- **Amazon S3:** Hosts the static resume website.
- **Amazon CloudFront:** Delivers website content securely over HTTPS.
- **AWS Lambda:** Handles visitor counter requests.
- **Amazon DynamoDB:** Stores visitor counter data.
- **Amazon API Gateway:** Connects the website to the Lambda function.
- **Terraform:** Provisions AWS infrastructure as code.
- **GitHub Actions:** Automates deployment and CloudFront cache invalidation.

## Key Features

- Cloud-hosted personal resume website.
- HTTPS delivery through CloudFront.
- Serverless visitor counter.
- Automated deployment using GitHub Actions.
- Infrastructure managed with Terraform.

## What I Learned

- Deploying and hosting websites using AWS.
- Managing cloud infrastructure with Terraform.
- Building serverless applications with Lambda and DynamoDB.
- Configuring automated CI/CD pipelines.
- Understanding cloud security and IAM permissions.
